# MetaCleaner

Проверка и очистка метаданных документов Microsoft Office (`.docx`, `.pptx`, `.xlsx` и версии с макросами) для Windows.

Программа показывает, что хранится внутри файла помимо текста: автор, организация, приложение-создатель, шаблон, даты, время правки, пользовательские свойства, авторы примечаний, EXIF изображений, служебные пути. Каждая находка получает оценку важности и подсказку, как её исправить. Затем свойства можно отредактировать вручную или очистить пакетно.

## Возможности

- Просмотр всех свойств документа и списка находок с оценкой (высокая, средняя, низкая).
- Редактирование автора, «кем сохранено», организации, комментария и других полей; массовое применение к выбранным файлам.
- Удаление пользовательских свойств, метаданных изображений (EXIF, PNG, C2PA), свойств встроенных диаграмм.
- Замена авторов примечаний и исправлений.
- Даты создания и изменения: оставить, задать или выбрать случайно в диапазоне; согласовать даты файла в Windows с датами документа.
- Правка текста: замена длинных тире, удаление разметки Markdown и служебных фраз, очистка альтернативного текста картинок, удаление меток `utm_source` из ссылок.
- Снятие отметки «Загружено из интернета».
- Пересохранение через установленный Microsoft Office (необязательно).
- Профили настроек; сохранение копий в подпапку `cleaned` или перезапись исходных файлов с резервной копией.

## Состав

| Папка | Что внутри |
|---|---|
| `src/Core` | Библиотека: чтение и запись пакетов OOXML, проверки, очистка |
| `src/App` | Оконное приложение (Windows Forms) |
| `src/Cli` | Консольная версия `metaclean` |
| `tests/samples` | Синтетические тестовые документы |
| `tools` | Скрипты Python для создания образцов и проверки результата |

## Консольная версия

```
metaclean inspect <файл|папка> [-r]
metaclean clean   <файл|папка> [-r] [--author ФИО] [--modified-by ФИО] [--comment текст]
                  [--company X] [--reviewer ФИО] [--in-place] [--no-backup] [--office-app]
                  [--plausible] [--resave] [--fix-text] [--dash endash|hyphen]
```

`-r` обходит вложенные папки. Без `--in-place` очищенные копии сохраняются в подпапку `cleaned`.

## Сборка

Нужен .NET SDK 8. Собирать можно и на Linux: для Windows-приложения включён `EnableWindowsTargeting`.

```bash
dotnet build MetaCleaner.sln -c Release

# Готовые exe одним файлом
dotnet publish src/App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o dist
dotnet publish src/Cli -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o dist
```

Готовые сборки выкладываются в разделе Releases.

## Проверка на образцах

```bash
pip install python-docx python-pptx openpyxl pillow
python tools/make_samples.py      # создаёт документы в tests/samples
metaclean clean tests/samples     # очищенные копии в tests/samples/cleaned
python tools/verify_cleaned.py    # проверяет, что файлы открываются и свойства очищены
```

## Требования

Windows 10 или 11, x64. Для пересохранения через Office нужен установленный Microsoft Office.
